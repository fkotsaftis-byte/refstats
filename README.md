# refstats.gr

Στατικό site με στατιστικά διαιτησίας της Super League. Τα δεδομένα έρχονται από το Google Sheet (δημοσιευμένα CSV, βλ. `config.json`). Κάθε 3 ώρες το GitHub ξαναχτίζει το site με τα νέα δεδομένα και το ανεβάζει στο refstats.gr.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `config.json` | Τα 4 links CSV του Sheet και το domain |
| `build.py` | Διαβάζει τα CSV και φτιάχνει όλες τις σελίδες στον φάκελο `public/` |
| `assets/style.css`, `assets/app.js` | Εμφάνιση και μικρές λειτουργίες (κουμπιά μετρικών, ταξινόμηση πινάκων) |
| `.github/workflows/build.yml` | Η αυτόματη ενημέρωση (κάθε 3 ώρες και με το κουμπί «Run workflow») |

## Άμεση ενημέρωση μετά από καταχώριση

Repository → καρτέλα **Actions** → «Ενημέρωση site» → **Run workflow** → **Run workflow**. Σε 1–2 λεπτά το site έχει τα νέα νούμερα.

## Αν κάτι πάει στραβά

Στην καρτέλα **Actions**, ένα κόκκινο ✗ σημαίνει ότι το χτίσιμο απέτυχε και το site κρατά την προηγούμενη έκδοση. Άνοιξε την αποτυχημένη εκτέλεση, αντέγραψε το μήνυμα λάθους και δώσ' το στο Claude.

Το GitHub σταματά τις προγραμματισμένες εκτελέσεις αν το repository μείνει 60 μέρες χωρίς αλλαγές, και στέλνει email. Αρκεί ένα κλικ στο «Enable workflow».
